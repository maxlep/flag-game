# Flag Game

A quiz for learning the flags of the world. Every answer shows what the flag's colours and symbols mean, look-alike flags are drilled against each other, and progress is saved in your browser. Master all 197 and you're the Flag Lord.

Built by prompting Claude: the ideas, testing and bug reports are mine; the code is Claude's.

Flag images from [flag-icons](https://github.com/lipis/flag-icons) (MIT) and, for official proportions, [svg-country-flags](https://github.com/hampusborgos/country-flags) (public domain).

## Layout

- `index.html` – markup and script tags
- `css/app.css` – styles
- `js/core/` – what doesn't touch the page: settings, progress, typed-answer matching, scope and regions, sorting, badges, the round
- `js/ui/` – what does: `screens/` (home, setup, quiz, results, study list, look-alikes, badges), `parts/` shared by them, `router.js` (which screen shows), `viewport.js` (the phone keyboard), `viewer.js` (zoom), `explore/` (the explorable map), `map.js` (draws a map as SVG)
- `js/boot.js` – starts the app
- `js/data/flags.js` – every flag: code, name, set, capital, description
- `js/data/groups.js` – look-alike sets and their hints
- `js/data/names.js` – typed-answer aliases, Wikipedia title overrides, official proportions, adoption years, regions of the non-country flags, flag variants
- `js/data/map.js` – Natural Earth outlines projected for the map, generated by `tools/build_map.js`
- `js/version.js` – commit time, written by `tools/stamp_version.py` before each commit
- `flags-true/` – artwork in official proportions, with civil, state and reverse variants as `<code>-<kind>.svg`; `flags/` – 4:3 fallback
- `tools/` – SVG edge snapping, data checks, version stamp, the map build, the claude.ai artifact fragment generator and the smoke test

Working conventions are in CLAUDE.md.
